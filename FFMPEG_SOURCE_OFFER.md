# FFmpeg build and source information

UniqueFlow Studio Full Beta 0.9.0-rc1 bundles the following unmodified Windows x64 shared GPL build:

- [Original BtbN release](https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-08-07-13-13)
- [FFmpeg revision `5c395992f99feb47860e4cc99a0cea2009457870`](https://github.com/FFmpeg/FFmpeg/commit/5c395992f99feb47860e4cc99a0cea2009457870)
- [Build-script revision `2437e7b868da3c11872367b15f3c613b87c24819`](https://github.com/BtbN/FFmpeg-Builds/commit/2437e7b868da3c11872367b15f3c613b87c24819)

UniqueFlow did not modify the FFmpeg or BtbN sources. The exact binary hashes and build configuration are included with the installer in `tools/ffmpeg/FFMPEG_BUILD_INFO.txt`.
