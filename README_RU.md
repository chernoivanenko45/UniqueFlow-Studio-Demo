# UniqueFlow Studio — Full Beta

UniqueFlow Studio — локальный Windows-редактор, который превращает исходные ролики и музыку в готовый короткий монтаж. Временная **Full Beta 0.9.0-rc1** даёт для тестирования настоящие режимы Standard и Deep AI. Это не публикация исходного кода.

## Что входит в бету

- Standard-монтаж с анализом ритма
- Deep AI Director с анализом сцен и музыки
- AI-трекинг и автоматическое кадрирование
- Улучшение видео и Photo AI
- Вариативный экспорт и локальная история результатов
- Загрузчик и Telegram-интеграция с собственным токеном пользователя
- Русский и английский интерфейс
- Локальная обработка медиа без телеметрии

Face Swap отключён, пока проверяются права на распространение его моделей.

## Скачивание и установка

1. Откройте [официальную страницу беты](https://chernoivanenko45.github.io/UniqueFlow-Studio-Demo/ru/).
2. Нажмите **Скачать Full Beta**, пока набор тестировщиков открыт.
3. Сверьте SHA-256 установщика со значением на странице.
4. Запустите установщик и следуйте подсказкам.

Размер пакета — около 902 МиБ; нужные компоненты уже включены. Текущая сборка не подписана цифровой подписью, поэтому Windows SmartScreen может показать предупреждение «Неизвестный издатель».
