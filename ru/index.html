Вопросы

Что важно знать.

UniqueFlow пока находится на ранней стадии. Честные отзывы напрямую влияют на следующие функции.

Демоверсия бесплатная?

Да. Версия 0.2.0 — ограниченная ознакомительная сборка со Standard-монтажом и видимым водяным знаком.

Видео загружаются в интернет?

Нет. Публичное демо обрабатывает выбранные файлы локально и не содержит телеметрии.

Почему Windows показывает предупреждение?

Ранняя сборка пока не подписана цифровой подписью, поэтому SmartScreen может показать «Неизвестный издатель». Скачивайте программу только из официального GitHub Release и сверяйте SHA-256.

Можно использовать любое видео?

Используйте только свои материалы или контент, на который у вас есть разрешение. Программа не предназначена для нарушения приватности, авторских прав или правил площадок.

Как связаться с разработчиком?
