Questions

Good to know.

UniqueFlow is still an early product. Honest feedback now directly influences what gets built next.

Is the demo free?

Yes. Version 0.1.1 is a limited evaluation build with a visible watermark.

Does it upload my videos?

No. The public demo processes selected media locally and contains no telemetry.

Why does Windows show a warning?

This early preview is not code-signed yet, so SmartScreen may show an “Unknown publisher” warning. Download only from the official GitHub Release and verify its SHA-256 value.

Can I use any video?

Use only media you own or have permission to process. The software must not be used to violate privacy, copyright or platform rules.

How can I contact the developer?

Write on Telegram at @zloy_tomych or open a GitHub issue.
